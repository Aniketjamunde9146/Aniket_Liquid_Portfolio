# Aniket Jamunde — Services and Pricing

Aniket Jamunde provides custom quotes for web development, Flutter app development, UI/UX design, cloud hosting, AI integration, game development, SEO, and maintenance.

## Pricing model

There are no fixed public rates. Each quote is based on the project's scope, required features, design complexity, integrations, content needs, timeline, and post-launch support.

## Service scopes

### Web development

Landing pages, portfolio websites, business websites, e-commerce experiences, React and Next.js builds, responsive UI, SEO-ready structure, analytics, contact forms, and performance optimization.

Typical delivery window: 1–3 weeks, depending on scope.

### App development

Cross-platform Flutter applications with Dart, Firebase, authentication, realtime data, push notifications, clean navigation, and store-submission support.

Typical delivery window: 3–8 weeks, depending on scope.

### Cloud hosting

Vercel deployment, custom domains, SSL, Firebase or Node.js setup, CI/CD pipelines, staging environments, monitoring, and deployment documentation.

Typical delivery window: 2–5 days, depending on setup complexity.

### AI and ML integration

LLM-powered chatbots, automation workflows, recommendation logic, API wrappers, prompt engineering, error handling, and usage-cost guidance.

Typical delivery window: 1–4 weeks, depending on scope.

### UI/UX, SEO, games, and support

Figma wireframes and prototypes, design systems, technical SEO audits, Core Web Vitals work, browser or mobile game features, bug fixes, security updates, and post-launch improvements are quoted individually.

Share the product or business goal, required pages or features, preferred timeline, and any reference websites or designs. Aniket will review the scope and reply with a tailored recommendation and quote.
